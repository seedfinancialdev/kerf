# Brand kit: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kerf wears its brand: the kit's colours in the app's tokens, IBM Plex Sans and Archivo bundled
with the app, a favicon, a README banner, and the kit itself kept in `docs/brand/` as the source of truth.

**Architecture:** The app keeps its own token names (`--color-bg`, `--color-text`, ...) and takes the kit's
values, so code written against today's names (including the M4.5 branch) keeps working; one misnamed token
(`--color-hover`, used only for selection) is renamed and three are added. Fonts come from `@fontsource`
packages bundled by Vite, so the app makes no third-party request. The logo files are hand-written SVG from
the kit's geometry; the banner is SVG with its text converted to outlines so it renders the same on GitHub.

**Tech Stack:** CSS custom properties, Vite 8, `@fontsource/ibm-plex-sans` 5.3.0 and `@fontsource/archivo`
5.3.0 (both published 2026-07-19), Vitest (node), Playwright, Biome.

**Spec:** the brand kit, approved by the maintainer on 2026-10-14/15: `docs/brand/README.md` and
`docs/brand/tokens.json` (both added in Task 1 from the kit made in Claude Design), and ADR 017 (Task 1),
which records the change to the Interaction spec's type rule. The maintainer approved replacing "the system
UI font at 12-13 px" with the kit's type on 2026-10-15.

## Review Focus

1. **A token renamed or dropped silently**: CSS falls back to nothing (transparent background, inherited
   colour) with no error. A test that every `var(--x)` in `styles.css` is defined in `tokens.css` catches it,
   and will catch the M4.5 merge too. Pinned in Task 2.
2. **`document.fonts.check()` lies**: it returns `true` for a family that is not in the font set at all, so a
   test built on it passes with no font bundled. The e2e test looks for a loaded `FontFace` named
   "IBM Plex Sans" instead. Pinned in Task 3.
3. **Offline and privacy**: the app must still open with the network off and must not call a font host.
   The e2e test fails on any request whose origin is not the app's. Pinned in Task 3.
4. **Light theme**: every pair is tested in both themes; the light theme's `danger` on inputs is the tightest
   text pair (4.51:1). Pinned in Task 2 by running every pair against both theme blocks.
5. **14 px in fixed-width panels** (232 px tree, 300 px inspector): longer labels may wrap or clip. No test can
   judge this; Task 5 takes screenshots of every step in both themes for the reviewer to look at.

```markdown
# ADR 017: The brand kit

Status: Accepted (maintainer, 2026-10-15).

## Context

ADR 010 set up design tokens "so the light theme and later branding are a token swap, not a redesign".
The maintainer commissioned a brand kit (made in Claude Design, reviewed against the codebase on
2026-10-14/15) and approved it. The kit lives in `docs/brand/`: the guide (`README.md`), the tokens
(`tokens.json`) and the logo files. The kit's type differs from the Interaction spec, which said "the system
UI font at 12-13 px in panels"; the maintainer approved the change on 2026-10-15.

## Decisions

| # | Decision | Why |
| --- | --- | --- |
| D1 | `docs/brand/` is the source of truth for colour, type and the logo. | One place to change the brand. |
| D2 | The app keeps its token names and takes the kit's values (table below). | Code written against today's names, including the M4.5 branch, keeps working; the kit's names describe the brand, the app's describe where a colour is used. |
| D3 | `--color-hover` is renamed `--color-selection`. | It was only ever used for the selected tree row; the kit says selection is a `signal-faint` wash and hover is a surface step. |
| D4 | `signal` blue replaces the oak accent for every state: the active step, the primary button, the selected tab, a pressed button, the focus ring. | The kit: "`signal` is the only colour that means UI state"; `wood` is never a state. |
| D5 | Inputs and buttons take the new `--color-border-strong` (3:1 on every surface); panel dividers keep `--color-border`. | WCAG 1.4.11: a control's boundary needs 3:1. The kit's `line` is decorative. |
| D6 | Type: IBM Plex Sans (400, 500, 600) for the interface at 14 px, 12 px for small text; Archivo 600 for headings. Replaces the Interaction spec's "system UI font at 12-13 px". | The kit's type. Plex has tabular numerals, which every dimension column needs; Archivo is the hosted face closest to the drawn wordmark. |
| D7 | Fonts are bundled from `@fontsource` (OFL-1.1), never loaded from Google Fonts. | Kerf works offline and calls no third party. |
| D8 | The logo is the drawn wordmark; the symbol is the icon (favicon, app icon, avatar), never set beside the wordmark. | The kit: a K before a word starting with K reads "K Kerf". |
| D9 | The favicon is one SVG that draws the symbol in `ink` for the browser's light or dark theme. | One file, crisp at 16 px (the kerf is exactly 1 px). |

| `--color-surface` (panels, top bar) | `surface-raised` | #262522 | #fbf9f5 |

| `--color-selection` (selected row) | `signal-faint` | #1a2f48 | #dbe8fa |
| `--color-border` | `line` | #34322e | #d9d4c9 |
| `--color-border-strong` | `line-strong` | #7a756e | #85807a |
| `--color-text` | `ink` | #ece7dd | #1d1c1a |
| `--color-text-muted` | `ink-muted` | #9a9589 | #66615a |
```

```ts
  ["text", "viewport"],
  ["text", "selection"],
```

```python
"""Prints an SVG <path> d attribute for a line of text set in a font file. Scratch tool; not committed."""
import sys
from fontTools.ttLib import TTFont
from fontTools.pens.svgPathPen import SVGPathPen
from fontTools.pens.transformPen import TransformPen

font_path, size, x, baseline, text = sys.argv[1], float(sys.argv[2]), float(sys.argv[3]), float(sys.argv[4]), sys.argv[5]
font = TTFont(font_path)
scale = size / font["head"].unitsPerEm
glyphs, cmap, hmtx = font.getGlyphSet(), font.getBestCmap(), font["hmtx"]
pen = SVGPathPen(glyphs, ntos=lambda v: f"{v:.2f}".rstrip("0").rstrip("."))
cursor = x
for ch in text:
    name = cmap[ord(ch)]
    glyphs[name].draw(TransformPen(pen, (scale, 0, 0, -scale, cursor, baseline)))
    cursor += hmtx[name][0] * scale
print(pen.getCommands())
print(f"advance={cursor - x:.2f}", file=sys.stderr)
```
