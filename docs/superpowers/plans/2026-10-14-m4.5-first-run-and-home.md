# M4.5: First run and Home: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kerf greets a woodworker properly: a pegboard to set up their shop on first launch, a SketchUp-style Home
with every project kept automatically, a New project panel with a live 3D preview, a short tour, and tooltips
everywhere; the Start step leaves the workshop.

**Architecture:** The store gains a `screen` ("shop" | "home" | "workshop") and a project library over IndexedDB
(a plain async module in `model/`, injected into the store like `storage`). The shop becomes an app-side record of
everything hung on the pegboard, from which a pure function derives the engine's `ShopProfile`; `@kerf/core` does
not change. New screens live in `ui/home/`, `ui/shop/`, `ui/new/`; the preview reuses the viewport's board
drawing through a split `BoardMesh` component.

**Tech Stack:** React 19, zustand (vanilla), three.js via @react-three/fiber, Vitest 5 (jsdom) + Testing Library,
Playwright, Biome, dependency-cruiser; new dev dependency `fake-indexeddb` (tests only).

**Spec:** `docs/superpowers/specs/2026-10-14-first-run-and-home-design.md` (approved 2026-10-14, with mockup
screenshots in `docs/superpowers/specs/2026-10-14-first-run-and-home/`). Read it before any task.

## Global Constraints

- Lengths are integers (1in = 203200 units, `INCH`; 1 mm = 8000, `MM`). No floats for lengths, ever.
- `packages/core` does not change in this milestone; the app imports only `@kerf/core`'s public API.
- `model/` imports no React, three.js, `state/`, `scene/`, `tools/`, `ui/` or `viewport/` (dependency-cruiser
  rule `app-model-has-no-screens`); `viewport/` never imports `ui/`; `tools/` imports no React.
- Save intent, derive geometry: the library stores the serialized project (`serializeProject`) and a picture,
  never derived cut lists or geometry.
- UI strings use shop language. Banned: mesh, vertex, face (geometry), component, instance, material, extrude,
  boolean (checked by `src/testing/banned-words.ts` and `e2e/wording.spec.ts`).
- Kerf's existing look: only tokens from `src/tokens.css` and the control styles in `src/styles.css` (buttons,
  `.primary`, `.steps`-style segmented control, `.tabs`, `.field`); the pegboard as in
  `2026-10-14-first-run-and-home/1-your-shop.png`.
- Familiar words: "Open file", "Recent files", "Templates", "New project", "Learn".
- Every new file starts with the three-line GPL header used across the repo.
- Every public function documented (what, units, errors); typed errors that say what to do; no dead code.
- Tests first and seen failing; expected values from the spec or a hand calculation, shown in a comment.
- Node 24 (`PATH=.../node-v24.21.0-darwin-arm64/bin:$PATH`); `pnpm lint`, `pnpm typecheck`, `pnpm test` clean
  before every commit.
- Commit trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A browser that cannot keep projects** (private window, IndexedDB blocked or full): Home must say so and keep
   saying so; no click may fail silently. Pinned in Task 6 (library unavailable) and Task 7 (store warns).
2. **The old single project** (`kerf.project`) must appear as the first card after upgrading, exactly once, and
   never be lost if the library cannot be written. Pinned in Task 6 (migration) and Task 13 (e2e upgrade).
3. **Typing sizes in New project:** empty, zero, negative, the gap bigger than the space, metric text in an
   imperial project ("900 mm"). Create stays off with a plain reason. Pinned in Task 5 and Task 10.
4. **Back and forward buttons** between Home, Your shop and the Workshop, and reloading on each; a reload in the
   Workshop returns to Home (the project is in Recent files). Pinned in Task 7 and Task 13.
5. **A skipped shop meets a joint that needs an unknown tool:** Kerf asks once, the answer is kept, and it never
   asks again. Pinned in Task 11.

```markdown
# ADR 016: First run and Home (M4.5)

Status: accepted (maintainer, 2026-10-14). Design: `docs/superpowers/specs/2026-10-14-first-run-and-home-design.md`.

## Context

M4's first use by the maintainer found a problem at every step, starting with the first screen. This milestone
redesigns how Kerf greets a woodworker and how a project begins, following the tools users already know
(SketchUp's Welcome window, Shapr3D's Dashboard).

## Decisions

- D1. **Screens.** Kerf has three: Your shop (first launch, and from Home or Settings), Home (every launch after),
  and the Workshop. The browser's Back button moves between them; a reload always lands on Home (or Your shop on
  a first launch).
- D2. **Start leaves the top bar.** The workshop's steps are Shape, Divide, Joinery, Build plan. Choosing a piece
  and its size moves to New project; opening and downloading files to Home and the project menu; the shop to
  Your shop. This changes Interaction spec §§ "The workflow", "1. Start", "Workflow modules", "Toolbar" and
  "Core flow" (updated with this ADR, approved by the maintainer).
- D3. **The shop record.** The app keeps everything hung on the pegboard, including tools and router bits the
  engine does not use yet, under `kerf.shop` (version 2). `shopProfileFor` gives the engine only what it
  understands: cut width, dado stack, router bits, hand-cut dovetails. A version 1 value (a `ShopProfile`) is
  read as a record told about every tool. `@kerf/core` does not change.
- D4. **Ask when it matters.** A shop that was skipped is the starter shop, not told about any tool. When a step
  needs a tool the record was never told about, it asks once, in place, and keeps the answer.
- D5. **Every project is kept.** Projects live in the browser's IndexedDB database `kerf` (store `projects`),
  written on every recorded change with a picture of the model when one is on screen. Save becomes "Download
  .kerf file"; Open adds a new project and never replaces one. The old `kerf.project` value moves into the
  library once, then is removed only after the library has it.
- D6. **Space to fill (simple).** Brought forward from v1: the piece's width is the space less a gap at each
  side, its height the space less one gap at the top; depth is as typed. Default gap 1/8".
- D7. **Router bits are edge shapes.** Edge profile offers the roundovers whose bits are on the router card;
  roundovers without a bit are offered greyed, with "Add it to my shop?"; chamfer, cove and ogee are kept on the
  wall and shown as *Later* (the engine draws roundovers only).
- D8. **Test changes.** `e2e/bookcase.spec.ts` gains one line: click **Create** after filling the size (the size
  is typed in New project, which then opens the workshop). `playwright.config.ts` seeds a set-up shop
  (`kerf.shop`) and a finished tour (`kerf.toured`) for the existing specs, which describe a returning user;
  first-run behaviour has its own spec with empty storage. Every other spec starts through
  `e2e/support/start.ts`.

## Consequences

- Removing the Start step changes `STEPS`, `hintFor`, the starting step (Shape), the inspector, and every test that
  named Start.
- The library is asynchronous; the store keeps a synchronous list of summaries refreshed after each write.
- Known limits: no folders, tags, sync or sharing; Inspiration, photos and describing a piece in words are later;
  router dados as an alternative to the dado stack are later.
```

```tsx
  afterEach(() => vi.useRealTimers());

    fireEvent.pointerEnter(screen.getByRole("button"));
    act(() => vi.advanceTimersByTime(499));
    expect(screen.queryByRole("tooltip")).toBeNull();

    expect(screen.getByRole("tooltip").textContent).toBe(

    expect(screen.getByRole("button").getAttribute("aria-describedby")).toBe(screen.getByRole("tooltip").id);
  });

  it("shows a neighbour's tip at once when the pointer moves straight to it", () => {
    render(
      <>
        <Tip tip={pushPull}><button type="button">Push/Pull</button></Tip>
        <Tip tip={move}><button type="button">Move</button></Tip>
      </>,
    );
    fireEvent.pointerEnter(screen.getByRole("button", { name: "Push/Pull" }));
    act(() => vi.advanceTimersByTime(500));
    fireEvent.pointerLeave(screen.getByRole("button", { name: "Push/Pull" }));
    fireEvent.pointerEnter(screen.getByRole("button", { name: "Move" }));
    expect(screen.getByRole("tooltip").textContent).toContain("Move or copy");

  it("shows on keyboard focus and hides on blur and Escape", () => {
    render(<Tip tip={pushPull}><button type="button">Push/Pull</button></Tip>);
    fireEvent.focus(screen.getByRole("button"));
    expect(screen.getByRole("tooltip")).toBeTruthy();
    fireEvent.keyDown(screen.getByRole("button"), { key: "Escape" });
    expect(screen.queryByRole("tooltip")).toBeNull();
  });
});
```

`Tip.tsx`: wraps exactly one child element (cloned with handlers and `aria-describedby`); a module-level
`lastHidden` timestamp makes a tip shown within 300 ms of another hiding appear at once; touch: a press of 500 ms
shows it; `role="tooltip"`; the tip is positioned below its control with `position: fixed` from
`getBoundingClientRect()`.

```tsx
// Kerf — free, open-source woodworking design tool
// Copyright (C) 2026 Kerf contributors
// SPDX-License-Identifier: GPL-3.0-only

// One tooltip for the whole app (design spec, "Tooltips"): the control's name, its key, and one line on what
// it does. SketchUp users expect a tip on every tool; keyboard users get it on focus, touch users on a long
// press.

import { cloneElement, type ReactElement, useEffect, useId, useRef, useState } from "react";

/** What a tip says. `key` is the shortcut, if any. */
export interface TipText {
  name: string;
  key?: string;
  text: string;
}

/** How long the pointer rests before the first tip shows, in milliseconds. */
const DELAY_MS = 500;
/** A tip shown within this long of another one hiding appears at once (moving along a row of tools). */
const SWEEP_MS = 300;

let lastHidden = Number.NEGATIVE_INFINITY;

type Trigger = ReactElement<{
  onPointerEnter?: () => void;
  onPointerLeave?: () => void;
  onFocus?: () => void;
  onBlur?: () => void;
  onKeyDown?: (e: { key: string }) => void;
  onPointerDown?: (e: { pointerType: string }) => void;
  onPointerUp?: () => void;
  "aria-describedby"?: string;
  ref?: React.Ref<HTMLElement>;
}>;

/** Shows `tip` for its one child control. */
export function Tip({ tip, children }: { tip: TipText; children: Trigger }) {
  const id = useId();
  const [shown, setShown] = useState(false);
  const [at, setAt] = useState<{ left: number; top: number }>({ left: 0, top: 0 });
  const target = useRef<HTMLElement | null>(null);
  const timer = useRef<number | undefined>(undefined);

  const place = () => {
    const box = target.current?.getBoundingClientRect();
    if (box) setAt({ left: box.left, top: box.bottom + 6 });
  };
  const show = () => {
    place();
    setShown(true);
  };
  const later = (ms: number) => {
    window.clearTimeout(timer.current);
    timer.current = window.setTimeout(show, ms);
  };
  const hide = () => {
    window.clearTimeout(timer.current);
    if (shown) lastHidden = performance.now();
    setShown(false);
  };
  useEffect(() => () => window.clearTimeout(timer.current), []);

  const trigger = cloneElement(children, {
    ref: (el: HTMLElement | null) => {
      target.current = el;
    },
    "aria-describedby": shown ? id : undefined,
    onPointerEnter: () => (performance.now() - lastHidden < SWEEP_MS ? show() : later(DELAY_MS)),
    onPointerLeave: hide,
    onFocus: show,
    onBlur: hide,
    onKeyDown: (e) => {
      if (e.key === "Escape") hide();
      children.props.onKeyDown?.(e);
    },
    onPointerDown: (e) => {
      if (e.pointerType === "touch") later(DELAY_MS);
      children.props.onPointerDown?.(e);
    },
    onPointerUp: () => {
      if (!shown) window.clearTimeout(timer.current);
      children.props.onPointerUp?.();
    },
  });

  return (
    <>
      {trigger}
      {shown && (
        <span role="tooltip" id={id} className="tip" style={{ left: at.left, top: at.top }}>
          <b>{tip.name}</b>
          {tip.key && <kbd>{tip.key}</kbd>}
          <span>{tip.text}</span>
        </span>
      )}
    </>
  );
}
```

```ts
// Kerf — free, open-source woodworking design tool
// Copyright (C) 2026 Kerf contributors
// SPDX-License-Identifier: GPL-3.0-only

// The shop as hung on the pegboard (ADR 016, D3). It keeps every tool and bit the woodworker owns, so Kerf
// already knows when later joinery needs them; the engine is given only what it understands today.

import { INCH, type Len, type ShopProfile, type Stock } from "@kerf/core";
import { STARTER_DADO_WIDTH, STARTER_STOCK } from "./starter";

/** The shape a router bit cuts. Edge shapes are sized by radius; straight bits by cutting width. */
export type BitShape = "roundover" | "chamfer" | "cove" | "ogee" | "straight" | "rabbeting";

/** One router bit on the router card. */
export interface RouterBit {
  shape: BitShape;
  /** Radius for edge shapes, cutting width for a straight bit (project units). */
  size: Len;
}

/** What "ask when it matters" can ask about (ADR 016, D4). */
export type ToolTopic = "saw" | "dadoStack" | "router" | "handTools";

/** Everything on the pegboard. A `null` tool is one the shop does not have. */
export interface ShopRecord {
  version: 2;
  /** True once the pegboard has been saved: every tool on it, hung or not, is then known. */
  setUp: boolean;
  tableSaw: { kerf: Len } | null;
  trackSaw: { kerf: Len } | null;
  dadoStack: { maxWidth: Len } | null;
  router: { bits: RouterBit[] } | null;
  drill: boolean;
  chisels: boolean;
  dovetailSaw: boolean;
  /** The wood new projects start with. */
  stock: Stock[];
  /** Topics answered one at a time after a skipped pegboard. */
  told: ToolTopic[];
}

/** The cut width assumed when the shop has no saw on its wall: a common 1/8" blade. */
export const DEFAULT_KERF: Len = INCH / 8;

/** The starter shop, as on a skipped pegboard: the same as M4's starter shop. */
export const STARTER_RECORD: ShopRecord = {
  version: 2,
  setUp: false,
  tableSaw: { kerf: DEFAULT_KERF },
  trackSaw: null,
  dadoStack: { maxWidth: STARTER_DADO_WIDTH },
  router: { bits: [{ shape: "roundover", size: INCH / 8 }] },
  drill: false,
  chisels: true,
  dovetailSaw: true,
  stock: [...STARTER_STOCK],
  told: [],
};

const sizesOf = (bits: readonly RouterBit[], shape: BitShape): Len[] =>
  bits.filter((b) => b.shape === shape).map((b) => b.size);

/** The engine's view of the shop: cut width, dado stack, router bits and hand-cut dovetails only. */
export function shopProfileFor(record: ShopRecord): ShopProfile {
  const tools: ShopProfile["tools"] = [];
  if (record.dadoStack) tools.push({ type: "dadoStack", maxWidth: record.dadoStack.maxWidth });
  if (record.router)
    tools.push({
      type: "router",
      straightBits: sizesOf(record.router.bits, "straight"),
      roundoverBits: sizesOf(record.router.bits, "roundover"),
    });
  tools.push({ type: "handTools", dovetails: record.chisels && record.dovetailSaw });
  return { kerf: record.tableSaw?.kerf ?? record.trackSaw?.kerf ?? DEFAULT_KERF, tools };
}

/** A version-1 saved shop (a `ShopProfile`) read as a set-up pegboard, so nothing it said is lost. */
export function recordFromProfile(profile: ShopProfile, stock: readonly Stock[]): ShopRecord {
  const dado = profile.tools.find((t) => t.type === "dadoStack");
  const router = profile.tools.find((t) => t.type === "router");
  const hand = profile.tools.find((t) => t.type === "handTools");
  return {
    ...STARTER_RECORD,
    setUp: true,
    tableSaw: { kerf: profile.kerf },
    dadoStack: dado ? { maxWidth: dado.maxWidth } : null,
    router: router
      ? {
          bits: [
            ...router.straightBits.map((size) => ({ shape: "straight" as const, size })),
            ...router.roundoverBits.map((size) => ({ shape: "roundover" as const, size })),
          ],
        }
      : null,
    chisels: hand?.dovetails ?? false,
    dovetailSaw: hand?.dovetails ?? false,
    stock: [...stock],
  };
}

/** True when the woodworker has said whether they have this tool (on the pegboard, or when asked). */
export function toldAbout(record: ShopRecord, topic: ToolTopic): boolean {
  return record.setUp || record.told.includes(topic);
}

/** The record after the woodworker answered a question about `topic`. */
export function answered(record: ShopRecord, topic: ToolTopic): ShopRecord {
  return record.told.includes(topic) ? record : { ...record, told: [...record.told, topic] };
}
```

```ts
// Kerf — free, open-source woodworking design tool
// Copyright (C) 2026 Kerf contributors
// SPDX-License-Identifier: GPL-3.0-only

// Space to fill (ADR 016, D6): a piece sized to an opening, leaving a gap at each side and at the top so it
// slides in. Whole-number lengths only.

import { INCH, type Len } from "@kerf/core";

/** A width, height and depth (project units). */
export interface Size3 {
  w: Len;
  h: Len;
  d: Len;
}

/** The piece's outside size, or why the space and gap cannot make one. */
export type Outside = { ok: true; size: Size3 } | { ok: false; message: string };

/** The gap a new project starts with: 1/8" (ADR 016, D6). */
export const DEFAULT_GAP: Len = INCH / 8;

/** The outside size of a piece that fills `space`, leaving `gap` at each side and at the top. */
export function outsideFromSpace(space: Size3, gap: Len): Outside {
  if (gap < 0) return { ok: false, message: "The gap can't be less than zero." };
  const size = { w: space.w - 2 * gap, h: space.h - gap, d: space.d };
  if (size.w <= 0 || size.h <= 0) return { ok: false, message: "The gap is bigger than the space." };
  return { ok: true, size };
}
```

```ts
// Kerf — free, open-source woodworking design tool
// Copyright (C) 2026 Kerf contributors
// SPDX-License-Identifier: GPL-3.0-only

// Every project kept in the browser's database (ADR 016, D5): IndexedDB database "kerf", object store
// "projects", keyed by project id. The project is stored as its saved text (intent only) with a picture.
// Nothing here throws: a browser that cannot keep projects says so through `available` and `write`.

import type { Id } from "@kerf/core";

/** One kept project. Times are ISO strings; `note` is the idea typed for "Something else". */
export interface LibraryEntry {
  id: Id;
  name: string;
  /** The project as `serializeProject` writes it. */
  project: string;
  /** A PNG picture of the model, or null when none could be taken. */
  thumbnail: Uint8Array | null;
  created: string;
  modified: string;
  note: string;
}

/** What Home shows for a project: everything but the project itself. */
export type ProjectSummary = Omit<LibraryEntry, "project">;

/** The browser's store of projects. */
export interface Library {
  /** False when the browser has no database or refused to open it. */
  readonly available: boolean;
  /** Every project, newest change first; empty when unavailable or unreadable. */
  list(): Promise<ProjectSummary[]>;
  read(id: Id): Promise<LibraryEntry | undefined>;
  /** True when the entry was kept. */
  write(entry: LibraryEntry): Promise<boolean>;
  /** True when the entry is gone. */
  remove(id: Id): Promise<boolean>;
}

/** Shown on Home while projects cannot be kept (design spec §2, "Keeping projects"). */
export const LIBRARY_NOT_KEPT =
  "This browser isn't keeping your projects. Download a .kerf file to keep your work.";

const DATABASE = "kerf";
const STORE = "projects";

const done = <T>(request: IDBRequest<T>): Promise<T> =>
  new Promise((resolve, reject) => {
    request.onsuccess = () => resolve(request.result);
    request.onerror = () => reject(request.error);
  });

const unavailable: Library = {
  available: false,
  list: async () => [],
  read: async () => undefined,
  write: async () => false,
  remove: async () => false,
};

/** Opens the library in `factory` (the browser's `indexedDB`); never rejects. */
export async function openLibrary(factory: IDBFactory | undefined): Promise<Library> {
  if (!factory) return unavailable;
  let db: IDBDatabase;
  try {
    const opening = factory.open(DATABASE, 1);
    opening.onupgradeneeded = () => opening.result.createObjectStore(STORE, { keyPath: "id" });
    db = await done(opening);
  } catch {
    return unavailable;
  }
  const store = (mode: IDBTransactionMode) => db.transaction(STORE, mode).objectStore(STORE);
  const attempt = async <T>(work: () => Promise<T>, otherwise: T): Promise<T> => {
    try {
      return await work();
    } catch {
      return otherwise;
    }
  };
  return {
    available: true,
    list: () =>
      attempt(async () => {
        const all = (await done(store("readonly").getAll())) as LibraryEntry[];
        return all
          .map(({ project: _project, ...summary }) => summary)
          .sort((a, b) => b.modified.localeCompare(a.modified));
      }, []),
    read: (id) => attempt(async () => (await done(store("readonly").get(id))) as LibraryEntry | undefined, undefined),
    write: (entry) => attempt(async () => (await done(store("readwrite").put(entry)), true), false),
    remove: (id) => attempt(async () => (await done(store("readwrite").delete(id)), true), false),
  };
}
```
